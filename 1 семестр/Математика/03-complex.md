# Комплексные числа

## 1. Алгебраическая форма

Комплексным числом $z$ называется выражение вида:
$$z = x + iy,$$
где $x, y \in \mathbb{R}$, а $i$ — **мнимая единица**, удовлетворяющая условию $i^2 = -1$.

- $x = \operatorname{Re}(z)$ — действительная (реальная) часть;
- $y = \operatorname{Im}(z)$ — мнимая часть.

### Арифметика в алгебраической форме
Пусть $z_1 = a + bi$ и $z_2 = c + di$:
- **Сложение:** $z_1 + z_2 = (a + c) + i(b + d)$
- **Умножение:** $z_1 \cdot z_2 = (ac - bd) + i(ad + bc)$
- **Сопряжение:** $\bar{z} = x - iy$. Заметим, что $z \cdot \bar{z} = x^2 + y^2 \in \mathbb{R}$.
- **Деление:** 
  $$\frac{z_1}{z_2} = \frac{(a + bi)(c - di)}{(c + di)(c - di)} = \frac{(ac + bd) + i(bc - ad)}{c^2 + d^2}.$$

---

## 2. Модуль и аргумент

- **Модуль:** $|z| = r = \sqrt{x^2 + y^2}$.
- **Аргумент:** Угол $\varphi = \operatorname{Arg}(z)$, определяемый с точностью до $2\pi k$:
  $$\cos \varphi = \frac{x}{\sqrt{x^2 + y^2}}, \quad \sin \varphi = \frac{y}{\sqrt{x^2 + y^2}}.$$
  Главное значение аргумента обозначается $\operatorname{arg}(z) \in (-\pi, \pi]$.

---

## 3. Тригонометрическая и показательная формы

### Тригонометрическая форма:
$$z = r(\cos \varphi + i \sin \varphi)$$

### Формула Эйлера и показательная форма:
$$e^{i\varphi} = \cos \varphi + i \sin \varphi \implies z = r e^{i\varphi}$$

---

## 4. Формула Муавра и возведение в степень

Для любого $n \in \mathbb{Z}$:
$$z^n = \big(r(\cos \varphi + i \sin \varphi)\big)^n = r^n (\cos n\varphi + i \sin n\varphi) = r^n e^{i n \varphi}.$$

---

## 5. Извлечение корней $n$-й степени

Уравнение $w^n = z$ имеет ровно $n$ различных комплексных корней:
$$w_k = \sqrt[n]{r} \left( \cos \frac{\varphi + 2\pi k}{n} + i \sin \frac{\varphi + 2\pi k}{n} \right), \quad k = 0, 1, \dots, n-1.$$

Геометрически корни $w_k$ образуют вершины правильного $n$-угольника, вписанного в окружность радиуса $\sqrt[n]{r}$ с центром в начале координат.

### Пример: Вычисление $\sqrt[3]{1}$
1. $r = 1, \varphi = 0$.
2. $w_k = \cos \frac{2\pi k}{3} + i \sin \frac{2\pi k}{3}, \quad k \in \{0, 1, 2\}$.
   - $w_0 = 1$
   - $w_1 = -\frac{1}{2} + i \frac{\sqrt{3}}{2}$
   - $w_2 = -\frac{1}{2} - i \frac{\sqrt{3}}{2}$

---

## 6. Квадратные уравнения над $\mathbb{C}$

Для уравнения $a z^2 + b z + c = 0$ с дискриминантом $D = b^2 - 4ac < 0$:
$$z_{1, 2} = \frac{-b \pm i \sqrt{|D|}}{2a}.$$
