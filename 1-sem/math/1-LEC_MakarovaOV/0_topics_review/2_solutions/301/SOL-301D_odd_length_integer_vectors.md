# Ответ к задаче 3.1 [D] — Целочисленные векторы нечётной длины

![[PST-301D_odd_length_integer_vectors]]

---

## Подробное решение

### Пункт а)
**Нет, сумма $\vec{a} + \vec{b} + \vec{c}$ не может равняться нулевому вектору $\vec{0}$.**

Докажем это с помощью анализа чётности суммы координат вектора.

Пусть $\vec{v} = (v_1, v_2, \dots, v_n) \in \mathbb{Z}^n$ — произвольный вектор с целыми координатами, длина которого равна нечётному целому числу $|\vec{v}| = 2m + 1$ ($m \in \mathbb{Z}$). По обобщению [[LEC-301_vectors#Длина вектора, заданного координатами|формулы длины вектора в координатах]] на $\mathbb{R}^n$:

$$
|\vec{v}|^2 = v_1^2 + v_2^2 + \dots + v_n^2 = (2m + 1)^2 = 4m^2 + 4m + 1 = 2(2m^2 + 2m) + 1.
$$

Таким образом, квадрат длины $|\vec{v}|^2$ — **нечётное** целое число.

Обозначим сумму координат вектора $\vec{v}$ через $S(\vec{v}) = v_1 + v_2 + \dots + v_n$. Рассмотрим разность между $|\vec{v}|^2$ и $S(\vec{v})$:

$$
|\vec{v}|^2 - S(\vec{v}) = \sum_{i=1}^{n} (v_i^2 - v_i) = \sum_{i=1}^{n} v_i(v_i - 1).
$$

Для любого целого числа $v_i \in \mathbb{Z}$ произведение двух соседних целых чисел $v_i(v_i - 1)$ всегда [[LEC-101_natural_and_integer_numbers#Делимость|делится]] на $2$ (одно из двух подряд идущих целых чисел чётно). Значит, вся сумма $\sum_{i=1}^n v_i(v_i - 1)$ является чётным числом ($2 \mid (|\vec{v}|^2 - S(\vec{v}))$).

Отсюда следует, что $S(\vec{v})$ имеет ту же чётность, что и $|\vec{v}|^2$, а именно — **сумма координат $S(\vec{v})$ каждого из векторов $\vec{a}, \vec{b}, \vec{c}$ является нечётным целым числом**:

$$
S(\vec{a}) = 2k_1 + 1, \qquad S(\vec{b}) = 2k_2 + 1, \qquad S(\vec{c}) = 2k_3 + 1 \qquad (k_1, k_2, k_3 \in \mathbb{Z}).
$$

Предположим от противного, что $\vec{a} + \vec{b} + \vec{c} = \vec{0}$. Тогда по правилу [[LEC-301_vectors#Сложение векторов и умножение вектора на число в координатах|сложения векторов в координатах]] для каждой координаты $i = 1, \dots, n$ выполнено $a_i + b_i + c_i = 0$. Просуммировав эти равенства по всем $i$ от $1$ до $n$, получим:

$$
S(\vec{a}) + S(\vec{b}) + S(\vec{c}) = \sum_{i=1}^{n} (a_i + b_i + c_i) = 0.
$$

Однако сумма трёх нечётных чисел всегда нечётна:

$$
(2k_1 + 1) + (2k_2 + 1) + (2k_3 + 1) = 2(k_1 + k_2 + k_3 + 1) + 1 \neq 0,
$$

так как $0$ — чётное число. Полученное противоречие доказывает невозможность равенства $\vec{a} + \vec{b} + \vec{c} = \vec{0}$.

### Пункт б)
**Да, ответ изменится:** для **четырёх** векторов сумма может равняться $\vec{0}$.

Приведём явный пример в $\mathbb{R}^n$ для любого $n \ge 1$. Возьмём первый стандартный орт $\vec{e}_1 = (1, 0, \dots, 0)$ и положим:

$$
\vec{a} = \vec{b} = (1, 0, \dots, 0), \qquad \vec{c} = \vec{d} = (-1, 0, \dots, 0).
$$

Все четыре вектора имеют целые координаты, длина каждого равна $1$ (нечётное целое число), а их сумма равна нулевому вектору:

$$
\vec{a} + \vec{b} + \vec{c} + \vec{d} = \vec{0}.
$$

*(При $n \ge 2$ все четыре вектора можно выбрать даже попарно различными, например $\vec{e}_1, -\vec{e}_1, \vec{e}_2, -\vec{e}_2$; а при $n \ge 3$ можно взять не только различные векторы, но и разные нечётные длины, например $(1, 2, 2, 0, \dots)$, $(-1, 2, 2, 0, \dots)$, $(0, -4, -3, 0, \dots)$ и $(0, 0, -1, 0, \dots)$ с длинами $3, 3, 5, 1$.)*

---

## Ответ
* **а)** Нет, невозможно (сумма координат каждого вектора нечётна, поэтому сумма координат трёх векторов тоже нечётна и не может равняться нулю);
* **б)** Да, изменится: для четырёх векторов сумма может быть равна $\vec{0}$ (например, $\vec{a} = \vec{b} = (1, 0, \dots, 0)$, $\vec{c} = \vec{d} = (-1, 0, \dots, 0)$).
