# Ответ к задаче 3.1 [C] — Разложение по компланарным векторам с параметром

![[PST-301C_parametric_coplanar_decomposition]]

---

## Подробное решение

### Пункт а)
Вычислим координаты линейной комбинации $\alpha\vec{a} + \beta\vec{b} + \gamma\vec{c}$ по [[LEC-301_vectors#Сложение векторов и умножение вектора на число в координатах|правилам операций в координатах]]:

$$
\alpha(1, 1, 0) + \beta(0, 1, 1) + \gamma(1, 2, 1) = (\alpha + \gamma, \; \alpha + \beta + 2\gamma, \; \beta + \gamma).
$$

По [[LEC-301_vectors#Орты осей и координаты вектора на плоскости и в пространстве|условию равенства векторов в координатах]] векторное равенство $\vec{d} = \alpha\vec{a} + \beta\vec{b} + \gamma\vec{c}$ равносильно системе линейных уравнений:

$$
\begin{cases}
\alpha + \gamma = 2, \\
\alpha + \beta + 2\gamma = 3, \\
\beta + \gamma = p.
\end{cases}
$$

Вычтем первое уравнение из второго:

$$
(\alpha + \beta + 2\gamma) - (\alpha + \gamma) = 3 - 2 \implies \beta + \gamma = 1.
$$

Сравнивая это равенство с третьим уравнением $\beta + \gamma = p$, видим, что система совместна **тогда и только тогда, когда $p = 1$** (при $p \neq 1$ получаем противоречие $1 = p$).

### Пункт б)
При $p = 1$ третье уравнение $\beta + \gamma = 1$ совпадает с разностью второго и первого уравнений, поэтому исходная система сводится к двум независимым уравнениям с тремя неизвестными:

$$
\begin{cases}
\alpha + \gamma = 2, \\
\beta + \gamma = 1.
\end{cases}
$$

Выберем $\gamma = t \in \mathbb{R}$ в качестве свободного параметра и выразим $\alpha$ и $\beta$:

$$
\alpha = 2 - t, \qquad \beta = 1 - t, \qquad \gamma = t \quad (t \in \mathbb{R}).
$$

*Проверка:* $(2 - t)(1, 1, 0) + (1 - t)(0, 1, 1) + t(1, 2, 1) = (2 - t + t, \; 2 - t + 1 - t + 2t, \; 1 - t + t) = (2, 3, 1) = \vec{d}$.

Поскольку свободный параметр $t$ можно выбирать произвольно, существует бесконечно много наборов $(\alpha, \beta, \gamma)$ — **разложение не единственно**.

### Пункт в)
Заметим, что среди исходных векторов $\vec{c} = (1, 2, 1) = (1, 1, 0) + (0, 1, 1) = \vec{a} + \vec{b}$. По [[LEC-301_vectors#Сложение и вычитание векторов|правилу параллелограмма (или треугольника)]] сумма двух векторов лежит в той же плоскости, что и сами слагаемые, поэтому векторы $\vec{a}, \vec{b}, \vec{c}$ [[LEC-301_vectors#Коллинеарные и компланарные векторы|компланарны]] (при отложении от общего начала они лежат в одной плоскости $\Pi$, проходящей через неколлинеарные векторы $\vec{a}$ и $\vec{b}$).

Это полностью объясняет оба факта из пунктов а) и б):
1. **Почему подходит только $p = 1$:** любая линейная комбинация $\alpha\vec{a} + \beta\vec{b} + \gamma\vec{c} = (\alpha + \gamma)\vec{a} + (\beta + \gamma)\vec{b}$ принадлежит той же плоскости $\Pi$. Вектор $\vec{d} = (2, 3, p)$ лежит в плоскости $\Pi$ только при $p = 1$ (когда $\vec{d} = 2\vec{a} + \vec{b}$); при $p \neq 1$ вектор $\vec{d}$ выходит из плоскости $\Pi$, поэтому не компланарен с $\vec{a}, \vec{b}, \vec{c}$ и не может быть выражен через них.
2. **Почему разложение не единственно:** поскольку $\vec{a} + \vec{b} - \vec{c} = \vec{0}$, к любому разложению вектора $\vec{d}$ можно прибавлять вектор $\vec{0}$ в виде $t(\vec{c} - \vec{a} - \vec{b})$ для любого $t \in \mathbb{R}$:

   $$
   \vec{d} = 2\vec{a} + \vec{b} + t(\vec{c} - \vec{a} - \vec{b}) = (2 - t)\vec{a} + (1 - t)\vec{b} + t\vec{c}.
   $$

---

## Ответ
* **а)** Только при $p = 1$;
* **б)** $(\alpha, \beta, \gamma) = (2 - t, \; 1 - t, \; t)$ для любого $t \in \mathbb{R}$; разложение **не единственно**;
* **в)** Векторы $\vec{a}, \vec{b}, \vec{c}$ компланарны ($\vec{c} = \vec{a} + \vec{b}$), поэтому их линейные комбинации не выводят из их общей плоскости $\Pi$ (куда $\vec{d}$ попадает лишь при $p = 1$), а зависимость $\vec{c} - \vec{a} - \vec{b} = \vec{0}$ даёт бесконечное семейство разложений.
