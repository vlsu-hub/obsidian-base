# Ответ к задаче 3.1 [B] — Округление координат и вектор смещения в $\mathbb{R}^4$

![[PST-301B_floor_lattice_vector_in_r4]]

---

## Подробное решение

### Пункт а)
По определению [[LEC-101_natural_and_integer_numbers#Целая часть и остаток|целой части числа]] $\lfloor x \rfloor$ — это наибольшее целое число, не превосходящее $x$ ($\lfloor x \rfloor \le x < \lfloor x \rfloor + 1$). Для координат точки $M(2.2, \, -1.6, \, 3.4, \, -0.2)$ получаем:

$$
\lfloor 2.2 \rfloor = 2, \qquad \lfloor -1.6 \rfloor = -2, \qquad \lfloor 3.4 \rfloor = 3, \qquad \lfloor -0.2 \rfloor = -1.
$$

*(Для отрицательных чисел $-1.6$ и $-0.2$ округление происходит влево на числовой прямой: $-2 \le -1.6 < -1$ и $-1 \le -0.2 < 0$.)*

Таким образом, точка имеет координаты $P(2, \, -2, \, 3, \, -1)$.

По [[LEC-301_vectors#Нахождение координат вектора по координатам его конца и начала|правилу нахождения координат вектора по точкам начала и конца]] (аналогичному для $\mathbb{R}^4$) вычтем координаты начала $P$ из координат конца $M$:

$$
\overrightarrow{PM} = (2.2 - 2, \; -1.6 - (-2), \; 3.4 - 3, \; -0.2 - (-1)) = (0.2, \; 0.4, \; 0.4, \; 0.8).
$$

### Пункт б)
Длину вектора в $\mathbb{R}^4$ вычислим по обобщению [[LEC-301_vectors#Длина вектора, заданного координатами|формулы длины вектора в координатах]]:

$$
|\overrightarrow{PM}| = \sqrt{0.2^2 + 0.4^2 + 0.4^2 + 0.8^2} = \sqrt{0.04 + 0.16 + 0.16 + 0.64} = \sqrt{1} = 1.
$$

### Пункт в)
Для произвольной точки $M(x_1, x_2, x_3, x_4) \in \mathbb{R}^4$ координаты вектора $\overrightarrow{PM}$ равны разностям между координатами и их целыми частями, то есть [[LEC-101_natural_and_integer_numbers#Целая часть и остаток|дробным частям]] координат:

$$
\overrightarrow{PM} = (x_1 - \lfloor x_1 \rfloor, \; x_2 - \lfloor x_2 \rfloor, \; x_3 - \lfloor x_3 \rfloor, \; x_4 - \lfloor x_4 \rfloor) = (\{x_1\}, \; \{x_2\}, \; \{x_3\}, \; \{x_4\}).
$$

Для любого действительного числа $x$ его дробная часть удовлетворяет двойному неравенству $0 \le \{x\} < 1$. Следовательно, для каждой из четырёх координат выполнено строгое неравенство $\{x_i\}^2 < 1$ (при $i = 1, 2, 3, 4$).

Запишем квадрат расстояния $PM = |\overrightarrow{PM}|$ и просуммируем эти четыре строгих неравенства:

$$
PM^2 = \{x_1\}^2 + \{x_2\}^2 + \{x_3\}^2 + \{x_4\}^2 < 1 + 1 + 1 + 1 = 4.
$$

Поскольку расстояние $PM \ge 0$, из $PM^2 < 4$ следует строгое неравенство $PM < \sqrt{4} = 2$.

---

## Ответ
* **а)** $P(2, \, -2, \, 3, \, -1)$, $\overrightarrow{PM} = (0.2, \; 0.4, \; 0.4, \; 0.8)$;
* **б)** $|\overrightarrow{PM}| = 1$;
* **в)** Доказано (через оценку $0 \le \{x_i\} < 1$).
