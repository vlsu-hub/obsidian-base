# Ответ к задаче 3.1 [A] — Векторы в четырёхмерном пространстве $\mathbb{R}^4$

![[PST-301A_vectors_in_r4]]

---

## Подробное решение

Правила [[LEC-301_vectors#Сложение векторов и умножение вектора на число в координатах|покоординатных линейных операций]], [[LEC-301_vectors#Орты осей и координаты вектора на плоскости и в пространстве|разложение по стандартным ортам]] и [[LEC-301_vectors#Длина вектора, заданного координатами|формула длины вектора]] в пространстве $\mathbb{R}^4$ устроены полностью аналогично случаю плоскости и трёхмерного пространства — с четырьмя координатами вместо двух или трёх.

### Пункт а)
Найдём координаты вектора $\vec{w} = 2\vec{a} + \vec{b}$, выполнив умножение на число и сложение покоординатно:

$$
2\vec{a} = 2 \cdot (1, 0, -2, 3) = (2, 0, -4, 6),
$$

$$
\vec{w} = 2\vec{a} + \vec{b} = (2 + (-2), \; 0 + 4, \; -4 + 2, \; 6 + (-1)) = (0, 4, -2, 5).
$$

Стандартные орты пространства $\mathbb{R}^4$ имеют вид $\vec{e}_1 = (1, 0, 0, 0)$, $\vec{e}_2 = (0, 1, 0, 0)$, $\vec{e}_3 = (0, 0, 1, 0)$, $\vec{e}_4 = (0, 0, 0, 1)$. Следовательно, разложение вектора $\vec{w}$ по этим ортам записывается так:

$$
\vec{w} = 0\vec{e}_1 + 4\vec{e}_2 - 2\vec{e}_3 + 5\vec{e}_4 = 4\vec{e}_2 - 2\vec{e}_3 + 5\vec{e}_4.
$$

### Пункт б)
Длина вектора $\vec{w} = (w_1, w_2, w_3, w_4)$ в $\mathbb{R}^4$ равна квадратному корню из суммы квадратов всех его координат:

$$
|\vec{w}| = \sqrt{w_1^2 + w_2^2 + w_3^2 + w_4^2} = \sqrt{0^2 + 4^2 + (-2)^2 + 5^2} = \sqrt{0 + 16 + 4 + 25} = \sqrt{45} = \sqrt{9 \cdot 5} = 3\sqrt{5}.
$$

---

## Ответ
* **а)** $\vec{w} = 4\vec{e}_2 - 2\vec{e}_3 + 5\vec{e}_4$ (координаты $\vec{w} = (0, 4, -2, 5)$);
* **б)** $|\vec{w}| = 3\sqrt{5}$.
